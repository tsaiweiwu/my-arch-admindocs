# Secrets handling

**Rule: this repo never holds a secret value. Record *where* a secret lives,
*who* can read it, and *how* to rotate it.**

## Inventory (locations only)

| Secret | Location | Rotation notes |
|---|---|---|
| Munge key | `/etc/munge/munge.key`, `/opt/mprov/cloack/var/munge.key`, Docker volume `arch_munge_key` | Cluster-wide restart of munge + all Slurm daemons |
| Slurm JWT signing key | `/var/spool/slurm/jwt_hs256.key` in slurmctld/slurmdbd/slurmrestd containers | Must be identical on all three |
| Slurm JWT token (for ColdFront) | `/opt/mprov/cloack/etc/slurm/slurm_jwt.token` | Renewed nightly by root cron (30-day life) |
| CLOACK stack secrets | `/opt/cloack/.env` and `*.env` (ai, cloack, entra, slack, trello, mta, wekafs, helpdesk) | Generated by `start.sh init`. Some rotate with container recreate |
| Postgres / MariaDB passwords | `.env` / container env | |
| LDAP admin password | `.env` | |
| Entra ID client secret | `/opt/cloack/entra.env` | **Has an expiry date in Entra. Track it** |
| ColdFront break-glass `admin` | Should be in a vault (`docs/break-glass-admin.md`) | Quarterly |
| BMC credentials | `/apps/helpers/bmc` (hard-coded), `/root/.idrac-credentials` | `/root/pw-rotate.log` shows a 2026-09-19 rotation |
| JDS Slack webhook | `/etc/jds-report/webhook` | |
| WEKA credentials | `/opt/cloack/wekafs.env`, `~/.weka/` | |
| GitHub deploy keys | `/root/.ssh/` | |
| NPM admin login / TLS keys | `/opt/mprov/cloack/var/npm/` | |
