# Job submit, billing & the cost gate

Skipjack charges for most usage. Two Lua plugins enforce this.

## `job_submit.lua` (server-side, slurmctld)

Three checks, in order:

1. **Partition × QOS.** Rejects the job if its QOS isn't in the partition's
   `AllowQos`. Catches clients that skip `cli_filter`.
2. **GPU stewardship.** Rejects jobs on a GPU partition that request no GPU.
   The user is told to use a CPU partition. This applies to free accounts too.
3. **Cost acceptance.** Paid submissions must opt in with `--comment=accept_cost`
   or `--export=ACCEPT_COST=1`. Free submissions (free partitions, `ssci-*` accounts,
   free QOS) pass straight through.

Config inputs (both generated by ColdFront, **don't hand-edit**):

- `/etc/slurm/qos_config.lua`: `free_partitions`, `free_account_prefixes`, `free_qos`.
  If the file exists but fails to parse, the plugin **fails closed on paid jobs**.
- `/etc/slurm/rates.lua`: dollar rates per partition (`coldfront export_rates_lua`).

## `cli_filter.lua` (client-side, login nodes)

Shows a `[BILLING]` cost estimate at `sbatch`/`srun` time, using the same
`rates.lua` and `qos_config.lua`. It's turned on in Zone 1 of `slurm.conf`
(`CliFilterPlugins=cli_filter/lua`) so configless login nodes get it too.

## SPANK `spank_reemit_cost.so`

Listed in `plugstack.conf`. Re-emits cost info for steps.

## Free resources

From `CLOACK.md`:

- `scavenger` partition / QOS
- `ssci-*` accounts (Schmidt)
- Sentinel "no-charge" IO numbers `5555555555` (JHU) / `9999999999` (Schmidt)
- PI-paused IO numbers (`CostCenter.billing_paused`) block paid submission on that account

## Admin checks

```bash
sbalance                         # usage / spend vs. cap for your accounts
sbalance -h                      # options (per PI / user)
sacct -j <jobid> -o jobid,account,partition,qos,alloctres%60,comment%30
docker exec coldfront coldfront help | grep -i -E 'billing|rates|qos'
```
