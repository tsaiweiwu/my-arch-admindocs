## Config files

All in `/opt/mprov/cloack/var/slurm/skipjack/` (`cdconf`), with `/etc/slurm/*` on mgmt02 symlinked to them:

| File | Purpose |
|---|---|
| `slurm.conf` | Main config. **Zone 1 (top) is "immutable"**: cluster identity, accounting, auth, plugins. **Zone 2** holds nodes / nodesets / partitions and is safe to edit |
| `gres.conf` | GPU device mapping (explicit, no NVML autodetect) |
| `cgroup.conf` | cgroup v2, `IgnoreSystemd=yes`, constrain cores/RAM/devices |
| `job_submit.lua` | Server-side gate: partition×QOS, GPU stewardship, cost acceptance |
| `cli_filter.lua` | Client-side cost preview at `sbatch`/`srun` |
| `qos_config.lua` | Free partitions/accounts/QOS. **Generated by ColdFront** (`export_qos_config`) |
| `rates.lua` | Per-partition billing rates. **Generated by ColdFront** (`export_rates_lua`) |
| `plugstack.conf` | SPANK: `myspank.so`, `spank_reemit_cost.so`, `spank_pyxis.so` (all `optional`) |
| `prolog.sh` / `epilog.sh` + `.d/` | Run-parts dispatchers (see [Prolog/epilog](../../systems/slurm/prolog-epilog.md)) |
| `slurm-mail` | `MailProg` wrapper: `s-nail` via `smtp://arch-mta:25`, From `skipjack-slurm@arch.jhu.edu` |

The directory is a git repo. Commit every change:

```bash
cdconf
git diff
git add -A && git commit -m "describe the change"
git push           # origin git@github.com:jhu-arch/mgmt02_conf.git
```

## Slurm volumes on mgmt02

`skipjack_slurm_state` (StateSaveLocation), `skipjack_slurm_logs`
(`/var/log/slurm`, also read by promtail), `arch_slurm_db_data` (MariaDB),
`arch_munge_key`, `arch_shared_slurm_*`.

## JWT token for CLOACK

Root's crontab refreshes a 30-day JWT for ColdFront/CLOACK at 03:00 daily:

```cron
0 3 * * * t=$(docker exec skipjack-slurmctld scontrol token lifespan=2592000 ...) && echo "$t" > /opt/mprov/cloack/etc/slurm/slurm_jwt.token
```

If that job stops running, ColdFront's Slurm integration breaks within 30 days.
